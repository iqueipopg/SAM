## A1 — sam_a1_protocol

**Qwen real** (top-level):
```
{
  "query": str,
  "protocol": {
    "framework": str,  // "PICO" | "SPIDER" | "PECO" | "PCC"
    "research_question": str,
    "population": str,
    "intervention": str,
    "comparator": str,
    "outcome": str,
    "original_query": str,
    "inclusion_criteria": list[str],
    "exclusion_criteria": list[str],
    "protocol_document": str,
    "prospero_draft": str
  },
  "pubmed_query": str
}
```

**Schema decision**:
- `query: str` — la pregunta del usuario.
- `protocol: ProtocolBody` — objeto anidado con los 11 campos Qwen.
- `pubmed_query: str` — boolean query construida.
- `version: Literal["V2"] = "V2"` — campo extra del spec; default fijo para anclar bloque.
- `search_date_cutoff: Optional[str] = None` — opcional, spec sugiere pero Qwen no lo emite.
- `literal_quotes_source: Optional[str] = None` — opcional.
- **Divergencia spec**: spec pedía `pico` anidado; Qwen los lleva flat dentro de `protocol`. Mantenemos Qwen-flat.

## A2 — sam_a2_search

**Qwen real**:
```
{
  "papers": [
    {
      "pmid": str,
      "doi": str,
      "title": str,
      "abstract": str,
      "authors": list[str],
      "journal": str,
      "year": str,        // NOTA: str, no int
      "sources": list[str]  // lista de DBs; spec proponía source_db singular
    }
  ],
  "stats": {
    "pubmed": int, "europepmc": int, "semantic_scholar": int, "google_scholar": int,
    "total_before_dedup": int, "total_after_dedup": int,
    "duplicates_removed": int, "search_sources": list[str]
  }
}
```

**Schema decision**:
- `papers: list[Paper]` con campos Qwen exactos. `pmid` es el `paper_id` canónico (usado para slugs).
- `stats: SearchStats` con los 8 campos. NO mapear a `n_total` flat (spec).
- **Divergencia spec**: spec proponía `id`, `source_db`, `n_total`, `queries_executed`. Alineamos a Qwen: `pmid`, `sources`, `stats.total_after_dedup`. `queries_executed` no se emite por Qwen → no se modela.

## A3 — sam_a3_screening (per-paper)

**Qwen real** (per-paper, dentro de `include`/`exclude`/`uncertain`):
```
{
  "pmid": str,
  "title": str,
  "decision": "INCLUDE" | "EXCLUDE" | "UNCERTAIN",
  "confidence": float,           // 0..1
  "votes": list[{"decision": str, "reasoning": str, "model": str}],
  "reasoning": str,
  "flags": list[str],
  "screening_confidence": float,
  "borderline": bool
}
```

**Schema decision**:
- Schema per-paper con los 9 campos Qwen exactos + campos comunes `AgentResultBase` (`agent`, `backend`, `timestamp`, `tokens_in/out: Optional[int]=None`).
- Enum `Decision = Literal["INCLUDE","EXCLUDE","UNCERTAIN"]` (mayúsculas, exactas).
- `paper_id` alias = `pmid` (campo separado para uniformidad con state.py, valor copiado).
- **Divergencia spec**: spec proponía `reason` y `criteria_evaluated`. Qwen usa `reasoning` (no `reason`) y `flags: list[str]` (no dict criteria_evaluated). Alineamos a Qwen.

## A4 — sam_a4_fulltext (per-paper)

**Qwen real** (per-paper):
```
{
  "pmid": str, "title": str, "abstract": str, "authors": list[str],
  "journal": str, "year": str, "doi": str, "pmcid": str,
  "full_text": str,
  "text_source": str,          // "abstract_only" | "pmc" | "unpaywall" | etc.
  "full_text_length": int,
  "sections": dict,            // section_name -> text (puede ser {})
  "oa_url": str | null,
  "fulltext_decision": "INCLUDE" | "EXCLUDE",  // NOTA: nombre con prefijo, NO `decision`
  "fulltext_reasoning": str,
  "exclusion_reason": str | null,
  "fulltext_votes": list[{"decision": str, "reasoning": str, "model": str}],
  "fulltext_confidence": float,
  "screening_confidence": float,
  "borderline": bool
}
```

**Schema decision**:
- Campos Qwen exactos + AgentResultBase. Enum `FulltextDecision = Literal["INCLUDE","EXCLUDE"]` (sin UNCERTAIN en A4).
- **Crítico**: usar `fulltext_decision`/`fulltext_reasoning`/`fulltext_votes`/`fulltext_confidence` literales (con prefijo), NO `decision`/`reasoning`. Esto se enforza también en el prompt de sam_a4.
- **Divergencia spec**: spec proponía decision genérico; alineamos a Qwen con prefijo.

## A5 — sam_a5_extraction (per-paper)

**Qwen real**:
```
{
  "pmid": str, "title": str, "authors": list[str], "journal": str, "year": str,
  "study_characteristics": {
    "study_design": str,          // "RCT" | "Cohort" | etc.
    "sample_size": int | null,
    "n_groups": {"intervention": int|null, "control": int|null} | null,
    "age_mean": float | null, "age_sd": float | null,
    "female_pct": float | null,
    "setting": str | null, "country": str | null,
    "followup_duration": str | null
  },
  "intervention_exposure": {       // NOTA: nombre nested, no `intervention` plano
    "name": str,
    "description": str,
    "comparator": str,
    "dose_duration": str
  },
  "outcomes": [{
    "name": str,
    "effect_size_type": str,       // "MD" | "SMD" | "OR" | "RR" | "HR" | "PROP"
    "effect_size_value": float | null,
    "ci_lower": float | null, "ci_upper": float | null,
    "p_value": float | null,
    ...  // otros campos como n_intervention, n_control, etc.
  }],
  "extraction_quality": str,       // "complete" | "partial" | "failed"
  "extraction_notes": str,
  "text_source": str,
  "sections_used": list[str],
  "extraction_confidence": str,    // "high" | "medium" | "low"
  "concordance": {
    "sample_size_match": bool,
    "outcomes_matched": int, "outcomes_discrepant": int,
    "outcomes_pass1_only": int, "outcomes_pass2_only": int,
    "flags": list[str]
  }
}
```

**Schema decision**:
- Campos Qwen exactos. `intervention_exposure` (no `intervention`). Outcomes con campos enumerados pero permisivos en effect_size_type (Literal extensible) y null en numéricos.
- AgentResultBase añadido.

## A6 — sam_a6_quality (per-paper)

**Qwen real**:
```
{
  "pmid": str, "title": str,
  "study_design_detected": str,    // "rct" | "observational" | "qualitative" (lowercase)
  "quality_assessment": {
    "tool": "RoB2" | "ROBINS-I" | "JBI",
    "domains": dict[str, {"judgment": str, "justification": str}],
    "overall": str,                // "Low" | "Some concerns" | "High" etc.
    "overall_justification": str
  },
  "quality_weight": float,         // 0..1
  "study_characteristics": dict,   // propagado desde A5
  "outcomes": list                 // propagado desde A5
}
```

**Schema decision**:
- Campos Qwen exactos. `study_design_detected: Literal["rct","observational","qualitative"]` (lowercase, exacto).
- `quality_assessment.tool: Literal["RoB2","ROBINS-I","JBI"]`.
- `domains` es dict permisivo (varía por tool: RoB2 = 5 domains, ROBINS-I = 7, JBI = 10).
- AgentResultBase añadido.
